Run IRONSIGHT yourself

IRONSIGHT needs a server to proxy its upstream feeds, so there is no hosted version. It runs locally with no API keys and no environment variables.

With Docker

git clone https://github.com/NoblerWorks-HQ/IRONSIGHT.git
cd IRONSIGHT
docker compose up --build

The multi-stage image is about 215 MB and runs as a non-root user. Open http://localhost:3000. To use a different host port, change the ports mapping in docker-compose.yml.

With Node.js

nvm use          # Node 22
npm install
npm run dev      # http://localhost:3000

For production run npm run build then npm start. Use the THEATER toggle in the header to switch between Iran / Israel and Russia / Ukraine.

Stack

Next.js, TypeScript, Tailwind CSS and Leaflet. There is no database and no separate backend: Next API routes proxy each upstream feed. Source and contribution guide are on GitHub.
